How it goes

The week
  1. 1We hop on a short call to go through the wires and the toolkit, and you tell me which apps you already have in mind, so the briefs match your plans.
  2. 2Then I get going and share bits as I work. I set up the brand as variables and components in Figma first, then use Claude with the Figma MCP to apply it across the wires, and spend my own time on the decisions and the details. It's the workflow I teach at Memorisely, so it's how I work every day. I've also built a component library from Figma tokens in React, so setting up a file that maps cleanly to code is something I care about a lot.
  3. 3We finish with a walkthrough of the Figma file and both briefs, where you can ask me whatever you want before it goes to a developer.
